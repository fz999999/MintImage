> 用途：交给设计师做 UI 重设计。
> 内容：**按现有代码 1:1 还原的全部页面 / 控件 / 位置 / 尺寸 / 间距 / 交互**，不含配色方案（配色另行讨论）。
> 单位：逻辑像素（Dp），100% 缩放。所有数值取自代码实际参数，标注 `文件:行号` 的位置可直接核对。

## 2. 屏幕一：主窗口（首页）

### 2.1 结构树

```
Scaffold(extendBody: true)
├── AppBar (56)
│   ├── title: Column[ 标题行, 副标题 ]   ← 两行文本，左对齐
│   ├── actions: [选择] [收藏夹] [搜索] [设置]   ← 左起向右

│   └── Column
│       ├── Expanded → 图墙（GridView）
│       └── 底部输入栏（不滚动，固定贴底）
└── 无 API Key 时：Body 换成 EmptyState（居中新引导卡）
```

## 7. 屏幕四：图片预览（`image_preview_page.dart`）

**形态**：独立全屏页面（push），黑底，无列表上下文。

## 13. 现状缺陷清单（设计时需一并解决）

按严重度排序，全部为布局/交互问题，不含配色：

1. **参数行整体等比缩小**：7 个控件挤一行，窗口变窄时字号被缩到不可读（`bottom_input_bar.dart:411`）。
2. **表单全宽无上限**：设置页、两个编辑页的卡片/输入框在 1440 宽窗口下宽 1400+（全库 0 处 maxWidth）。
3. **窗口拖窄触发「手机模式」**：短边 < 600 时网格切 2 列、间距变 8（`image_list_widget.dart:289`），判定用了窗口尺寸而非设备类型。
4. **无最小窗口尺寸**：可拖到 300 宽，布局全部崩坏。
5. **缩略图被裁**：固定 206 高 + cover，竖图/横图丢失主体。
6. **图卡信息过载**：图上叠 6 个 10px 的 chip，缩略图几乎被遮。
7. **所有弹层都是底部升起**：切配置/模型/背景要跨越半屏（10+ 处 showModalBottomSheet）。
8. **无 hover / 无右键 / 无滚动条**：鼠标用户没有任何反馈，也找不到隐藏操作。
9. **删除依赖左滑**：设置页删除配置、收藏夹删除，桌面上不可发现。
10. **设置页单列长龙**：8 个区块纵向堆叠，滚动 3 屏，无分组导航。
11. **保存按钮随内容滚走**：配置编辑页要滚到底才能保存。
12. **预览是独立页面**：离开图墙；窄窗口下箭头与信息面板重叠。
13. **搜索条推挤布局**：展开时图墙整体跳动 52px。
14. **信息层级靠阴影/圆角**：13 种圆角、9 种字号无规则。
15. **无状态栏**：看不到总数、选中数、当前模型、任务队列。
