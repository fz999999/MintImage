# 大川生图工具 · Windows 界面现状说明

> 本文件**只记录当前界面的实际状态**：页面、布局、元素、尺寸、颜色、文案、交互与实现方式。
> 不含评价、不含问题清单、不含优化建议。

- 平台：Windows 桌面（仓库中 `android/`、`ios/`、`macos/` 不维护）
- 单位：px，按 100% 缩放记录
- 数据来源：直接读取 `lib/` 下 UI 代码得出

---

## 1 窗口与运行形态

| 项 | 现状 |
|---|---|

| 可缩放 | 是，无最小/最大尺寸限制 |
| 边框 | 系统原生标题栏（未自定义） |

### 2.5 阴影、模糊、渐变

| 名称 | 参数 |
|---|---|
| 卡片阴影 | 颜色 = 主色 8% 透明，blurRadius 24，spreadRadius −6，offset (0, 12) |
| 浮层阴影 | 颜色 = 主色 8% 透明，blurRadius 28，spreadRadius −8，offset (0, 14) |

| 状态胶囊 | 投影 blurRadius 10，颜色为黑 8%–12% |

## 18 组件实现方式（事实）

| 区域 | 使用的组件 / 方式 |
|---|---|
| 页面骨架 | `Scaffold` + `AppBar` + `Column` |
| 顶部栏 | `AppBar.title`（两行 `Column`）、`AppBar.actions`（`IconButton`） |
| 搜索条 | `AppBar.bottom` + `AnimatedContainer` |
| 图墙 | `LayoutBuilder` + `GridView.builder` + `Image.file` |
| 图卡 | `Stack` + 多个 `Positioned` 浮层 |
| 输入栏 | `Container` + `BackdropFilter` + `TextField` + `Row` |
| 参数入口 | `PopupMenuButton`（下拉）/ 自定义按钮（打开面板） |
| 面板 | `showModalBottomSheet`（`isScrollControlled`） |
| 对话框 | `showDialog` + `AlertDialog` |
| 预览 | `Navigator.push` + `PhotoView` |
| 左滑删除 | `flutter_slidable` |
| 设置页列表 | `ListView` + 自定义卡片 |
| 日志 | `ExpansionTile` |
| 图标 | `Icons.*`（Material Rounded 形状） |
| 字体 | `GoogleFonts.manrope` |
| 提示 | `Tooltip` 4 处；`SnackBar` 若干 |
| 空状态 | 自定义 `EmptyState` 组件 |
| 标题动画 | `AnimatedContainer` / `AnimatedOpacity` / `AnimatedSwitcher` |
