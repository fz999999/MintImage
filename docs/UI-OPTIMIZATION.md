# 大川生图工具 · Windows 界面优化方案

> 输入：`docs/UI-CURRENT-STATE.md`（现状事实记录）+ `lib/` 实际代码核验。
> 本文件给出问题诊断、优化后的界面方案、可直接落地的代码改造清单。
> 定位：桌面优先的生图工作台，不是移动端 App 的放大版。

---

## 0 一句话结论

现状是一套**为触屏设计的移动端界面**被直接放进了 Windows 窗口：靠长按和左滑触发操作、没有悬停态、没有右键菜单、没有快捷键、没有滚动条、没有拖放、没有暗色。视觉上又缺少约束层，圆角 14 种、字号 9 档、47 处硬编码颜色，导致"看起来像半成品"。

优化的主线只有三条：

1. **桌面交互补齐** —— 让鼠标成为一等公民（悬停、右键、滚轮、拖放、双击）。
2. **布局重构** —— 三栏工作台替代"顶栏 + 图墙 + 悬浮输入框"，参数不再挤成一排。
3. **设计系统收敛** —— 用一套 token 管住圆角、字号、间距、语义色，并补上暗色主题。

## 1 诊断：按优先级分级

### P0 桌面基础能力缺失（阻断级）

| # | 问题 | 代码证据 | 桌面上的后果 |
|---|---|---|---|
| P0-1 | 全库零 `MouseRegion` | 仅输入框 `Focus` 有交互反馈 | 没有 hover 态，用户不知道图卡可点、可拖、可删 |
| P0-2 | 无右键菜单 | 全库无 `onSecondaryTap` | 桌面用户的第一反射动作完全失效 |
| P0-3 | 无快捷键体系 | 无 `Shortcuts` / `Actions`，仅 `Enter` / `Ctrl+V` | 专业工具没有键盘效率，重复操作全靠鼠标 |
| P0-4 | 无滚动条 | `GridView` 无 `Scrollbar` | 1280×720 下图墙通常只能露出一行半，用户不知道下面还有内容 |
| P0-5 | 不支持拖放文件 | 无 `DragTarget` | 桌面端最自然的一次操作（把图拖进输入框）没有 |
| P0-6 | 破坏性操作只能靠左滑 | `settings_page.dart` 用 `flutter_slidable` | 鼠标用户永远发现不了"能删除配置" |
| P0-7 | 生成进度不在顶栏 | 进度只落在图卡 | 多任务并发时无法判断整体状态 |

## 2 优化后的界面方案

### 2.1 总体布局：三栏工作台

现状是"上下两段"（顶栏 + 图墙 + 悬浮输入框），所有操作挤在一条 56px 的顶栏里。优化为**左导航栏 + 中央画布 + 右侧上下文面板 + 底部输入栏**：

```
┌─────────────────────────────────────────────────────────────────────┐
│ ▣ 大川生图工具          [ 搜索提示词…            🔍 ]     ⬤ 2 生成中  │ 56
├────────────┬────────────────────────────────────┬───────────────────┤
│ 导航 216   │                                    │  上下文 320       │
│            │        图墙（自适应列数）           │                   │
│ ◎ 全部     │                                    │  ┌─────────────┐  │
│ ★ 收藏夹   │  ┌──────┐ ┌──────┐ ┌──────┐        │  │   选中图预览 │  │
│   · 默认   │  │      │ │      │ │      │        │  └─────────────┘  │
│   · 灵感   │  └──────┘ └──────┘ └──────┘        │  提示词全文        │
│            │                                    │  元信息网格        │
│ ▤ 设置     │  ┌──────┐ ┌──────┐ ┌──────┐        │  ─────────────    │
│   API      │  │      │ │      │ │      │        │  复用 · 改图 · ⋯   │
│   优化     │  └──────┘ └──────┘ └──────┘        │                   │
│   数据     │                                    │                   │
│   日志     │                                    │                   │
├────────────┴────────────────────────────────────┴───────────────────┤
│ ┌───────────────────────────────────────────────────────────────┐   │
│ │ 附件缩略图…                                          [停止][↑] │   │
│ │ 提示词输入区（可 6 行）                                     │   │
│ │ [尺寸 1024²] [质量 高] [数量 4] [格式 PNG]   ⚙ 更多参数 ▾     │   │
│ └───────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

**收益：**

- 顶栏从 5 个平级按钮减到 3 组（搜索 / 生成状态 / 设置），主次清晰。
- 左栏把「收藏夹」「设置项」从弹层里解放出来，收藏夹切换零成本。
- 右栏把「选图 → 看图 → 复用/改图」串成一条线，不必来回跳页。
- 底栏参数区分两行：高频 4 项常显（尺寸/质量/数量/格式），低频 3 项（背景/渠道/模型）收进「更多参数」。

### 2.2 图卡：悬停浮层 + 真实比例

**现状：** 单击进预览，长按/⋯ 出 9 项菜单，多选角标常驻左上。没有 hover，没有右键。

**优化后：**

| 元素 | 现状 | 优化后 |
|---|---|---|
| 悬停 | 无 | 卡片抬升 2px + 阴影加深 + 右上角浮现操作条（复制/下载/收藏/更多） |
| 右键 | 无 | `onSecondaryTap` 打开与 ⋯ 相同的菜单 |
| 尺寸角标 | 常驻右上 | 悬停时淡出（信息让位给操作） |
| 元信息条 | 常驻图内底部 | 悬停时淡出，避免遮挡主体 |
| 多选角标 | 常驻左上 22×22 | 仅多选模式显示；非多选模式不占视觉 |
| 图片比例 | 固定 206 高 + `cover` | 按真实比例自适应格高（1:1 / 16:9 / 9:16 各按自己的高） |

元信息默认只显示 2 项（比例 + 耗时），渠道/格式/质量在右栏上下文面板里完整展示——图卡上信息太多会挤压主体。

### 2.3 底部输入栏：参数分两行 + 拖放区

**现状痛点：** `FittedBox(scaleDown)` 把 7 个入口硬塞一行，窗口窄到 900px 时整行被缩到 70%，文字发虚不可读。

**优化后：**

```
╭─────────────────────────────────────────────────────────────────╮
│ [附件][附件]                                          ⏹  ↑     │ 48
│ ┌───────────────────────────────────────────────────────────┐   │
│ │ 描述你想生成的画面…                                       │   │ 自适应 40–160
│ └───────────────────────────────────────────────────────────┘   │
│ [尺寸 1024×1024 ▾] [质量 高 ▾] [数量 4 ▾] [格式 PNG ▾] [⚙ 更多] │ 32
╰─────────────────────────────────────────────────────────────────╯
   ↑ 点击整栏进入拖放态（描边变主色 + 半透明蒙层「松开即可添加图片」）
```

- 用 `Wrap` 替代 `FittedBox`：空间不够就换行，绝不缩放文字。
- 「更多参数」展开后是锚定在按钮上方的浮层（不是从底部升起），含背景/渠道/模型 + 「打开 API 设置」。
- 拖入图片文件 → 自动填充附件。

### 2.4 设置页：左侧分组导航

现状 7 个区块单列长滚。优化为左导航 + 右内容，选中项高亮，支持锚点滚动。

| 分组 | 内容 |
|---|---|
| 连接 | 生图 API（列表 + 新增）、提示词优化 API |
| 运行 | 请求超时、并发数 |
| 数据 | 数据备份（导出/恢复/WebDAV）、清除历史、本地存储位置 |
| 诊断 | 请求日志 |
| 关于 | 版本、开源地址、存储占用 |

### 2.5 预览页：键盘优先 + 信息不遮挡

- **键盘**：`←/→` 切换、`Esc` 返回、`空格` 切换信息面板、`F` 收藏、`Ctrl+S` 保存、`+/-` 缩放、`0` 适应窗口。（现状仅 `←/→` 生效）
- **布局**：信息面板从"覆盖在图上"改为"右侧分栏"（宽屏时）or"底部可完全收起"（窄屏时），默认收起 8%，鼠标靠近时展开——保证看图时不挡画面。
- **顶部工具条**：返回 / 保存 / 收藏 / 改图 / 信息开关，全部带 Tooltip。

### 2.6 视觉系统收敛

#### 圆角：14 种 → 5 种

| Token | 值 | 用途 |
|---|---|---|
| `radiusXs` | 6 | 元信息胶囊、内联徽章 |
| `radiusSm` | 10 | 图卡、按钮、输入框 |
| `radiusMd` | 14 | 面板、卡片 |
| `radiusLg` | 20 | 对话框、浮层、输入栏容器 |
| `radiusFull` | 999 | 状态胶囊、头像 |

#### 字号：9 档 → 7 档（全部走 TextTheme）

| Token | 值 | 用途 |
|---|---|---|
| `displaySm` | 28 | 空态标题 |
| `titleLg` | 20 | 页面标题 |
| `titleMd` | 16 | 区块标题 |
| `bodyLg` | 14 | 正文、输入框 |
| `bodyMd` | 13 | 卡片描述 |
| `labelMd` | 12 | 标签、次要文字 |
| `labelSm` | 11 | 图标旁文字、时间 |

#### 颜色：补齐语义 + 状态色进 token

```dart
// 补 6 个语义色，消除硬编码
static const successSurface = Color(0xFFE4F6EE);
static const successText    = Color(0xFF177245);
static const infoSurface    = Color(0xFFE8F3FF);
static const infoText       = Color(0xFF1667C5);
static const neutralSurface = Color(0xFFF1F5F9);
static const neutralText    = Color(0xFF475569);

// 透明度收敛为 5 档语义命名
static const overlayLight  = 0.06;  // hover 底色
static const overlayMedium = 0.12;  // 按下态
static const scrimLight    = 0.72;  // 弹层遮罩
static const glassFill     = 0.86;  // 玻璃输入栏
static const chipFill      = 0.92;  // 图内胶囊
```

#### 图标尺寸：12 种 → 4 种

`12`（内联）· `16`（按钮）· `20`（工具栏）· `28`（空态/品牌）。全部 Material Rounded，不再出现 13/15/17/19/34/42。

#### 阴影：3 档

| Token | 参数 | 用途 |
|---|---|---|
| `shadowCard` | 主色 6%，blur 16，offset(0,4) | 图卡常态 |
| `shadowRaised` | 主色 12%，blur 28，offset(0,10) | 悬停 / 浮层 |
| `shadowInput` | 黑 6%，blur 24，offset(0,8) | 底部输入栏 |

#### 暗色主题（新增）

`MaterialApp` 补 `darkTheme` + `themeMode: ThemeMode.system`。暗色下：
- canvas `#0F172A`，surface `#1E293B`，surfaceSoft `#243349`
- textPrimary `#E2E8F0`，textSecondary `#94A3B8`，border `#334155`
- primary 提亮到 `#22D3EE` 保证在暗底上的对比度 ≥ 4.5:1
- 预览页保持纯黑（图片查看器本来就该是黑的）

## 4 实施路线

### 第一阶段：视觉系统收敛（低风险，先做）

1. 建 `tokens.dart` / `app_colors.dart`
2. 全局替换圆角、字号、颜色、阴影、透明度
3. 补暗色主题 + `themeMode: system`
4. 图标尺寸归一到 4 档

**收益**：界面立刻从"半成品"变成"有系统"。不改任何交互，零回归风险。

### 第二阶段：桌面交互补齐

1. `HoverBuilder` 上图卡、图卡操作条
2. `AppContextMenu` 上图卡、设置配置卡
3. 全局 `Shortcuts` / `Actions` + 快捷键帮助面板
4. `Scrollbar` 全局接入，删 `RefreshIndicator`
5. 设置页删除改为 hover ⋯

**收益**：桌面"手感"从 0 到 60 分。

### 第三阶段：布局重构

1. `AppShell` 三栏骨架
2. 图卡真实比例 + 参数 `Wrap` 两行
3. 设置页左导航
4. 预览页分栏 + 补全键盘
5. `DragTarget` 拖放

**收益**：信息密度和操作效率的实质提升。

## 5 需要验证的点

- `FittedBox` 换成 `Wrap` 后，900px 窗口宽度下参数行会换到 2 行，输入栏总高从 96 涨到 130，需确认不会遮挡过多图墙（建议同时把图墙底部 padding 从 12 提到 24）。
- 列数下限提到 3 之后，600px 窄窗口下 3 列 × 最小 160px + 间距 = 500px，需实测是否溢出。
- 暗色下 `primary #22D3EE` 用于按钮底色时，白色文字对比度约 2.6:1，不达标——按钮文字需改深色 `#04222B`，或按钮仍用 `#0E7490` 底 + 白字。**这一条必须实测**。
