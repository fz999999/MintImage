## 八、连带硬要求

1. **P0 不可省**：暗色 + token 层是新 UI 的地基，任何「直接照搬 Stitch 深色」的做法都会与 233 处亮色常量打架。
2. **测试契约**：第 15/17 条会改 `test/features/input/bottom_input_bar_test.dart`（5 个 Key 保留、文案断言同步）；第 8 条不动 `test/features/image_list/image_cell_test.dart` 的状态文案；退出确认文案（`test/app_exit_confirmation_test.dart`）不动。
3. **输入框 40px 是红线**：按钮放大到 40 但输入框本体不变。
4. **零引用文件直接删**：`lib/features/input/selector_button.dart`（84 行，0 调用）。
5. **日志页可并行**：只换肤 + 概览卡改版，不占关键路径。
